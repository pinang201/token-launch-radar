Implied value TVL × peer multiple × growth factor × maturity factor

The peer multiple is the market-cap / TVL multiple of protocols whose token already trades, taken per category and per chain and shrunk toward the market-wide median when a group has few peers. Growth reads the protocol's 7-day TVL change; maturity reads how long it has run with no token. No protocol is priced by name — the same arithmetic prices every row.
